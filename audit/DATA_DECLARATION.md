# NEXA data declaration

**Internal owner declaration — provenance is owner-attested, not independently verified.**

NEXA Executive Intelligence is a demonstration application developed using synthetic banking data created specifically for this project.

The dataset was populated using AI-generated SQL scripts and CSV imports. No live banking systems were intentionally connected or used as data sources.

All customer, account, transaction, lending and risk scenarios are intended to be fictional.

Original generation artifacts are no longer available; therefore, data provenance is owner-attested rather than independently verified.

Purpose: Portfolio demonstration and illustration of executive intelligence, data governance and banking analytics capabilities.
